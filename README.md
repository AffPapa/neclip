# NeClip — менеджер буфера обмена для Mac и альтернатива Maccy, Paste и Raycast

NeClip — небольшое приложение для истории буфера обмена и папок сниппетов. Сохраняет тексты, изображения и файлы, помогает найти нужную копию и повторно использовать готовые ответы. Работает в строке меню на Mac с Apple Silicon и macOS 14 или новее.

История и сниппеты остаются на этом Mac. Нет учётной записи, облачной синхронизации, рекламы, телеметрии и обработки содержимого буфера обмена с помощью ИИ.

**Ищете менеджер буфера обмена для Mac, локальную историю копирования или альтернативу Maccy, Paste либо Raycast?** Посмотрите [сравнение 18 приложений для Mac](https://affpapa.github.io/neclip/compare.html) и выберите вариант под свой сценарий.

## История копирования, сниппеты и сочетания клавиш

Скопируйте текст, откройте историю, выберите запись и нажмите Return. Если macOS разрешила NeClip использовать функцию универсального доступа, приложение отправит вставку в исходное приложение. Без этого разрешения оно скопирует выбранный элемент для ручной вставки. Command-Return копирует без вставки, Shift-Return вставляет обычный текст.

| Сочетание клавиш по умолчанию | Действие |
|---|---|
| Command-Shift-V | Открыть историю буфера обмена |
| Command-Shift-B | Открыть папки сниппетов |
| Control-Command-V | Перейти к следующему недавнему элементу |

Все три глобальных сочетания клавиш можно изменить. Если сочетание занято, приложение сохраняет предыдущую рабочую настройку и показывает альтернативный пункт меню. Щёлкните значок NeClip правой кнопкой, чтобы открыть сниппеты.

История поддерживает локальный поиск по тексту, типу, приложению и дате. Папки сниппетов можно создавать, переименовывать и удалять; сниппеты из удалённой папки остаются в библиотеке. Шаблоны поддерживают `{date}`, `{time}`, `{clipboard}`, `{date:iso}` и `{time:iso}`.

## Конфиденциальность и хранение данных

История хранится локально в `~/Library/Application Support/NeClip/neclip.sqlite`. Удаление приложения не удаляет эту базу. NeClip не выполняет автоматическое распознавание текста на изображениях. Чувствительные системные типы буфера и известные защищённые источники исключаются, но не все приложения сообщают о чувствительных данных надёжно.

Резервные копии — обычные пользовательские файлы, они не зашифрованы автоматически. Храните их в безопасном месте и сделайте резервную копию перед обновлением. Экспорт сниппетов в JSON объединяет папки с одинаковыми именами; для полной копии библиотеки используйте встроенную резервную копию базы.

Для обычной работы функция универсального доступа необязательна. Она нужна для автоматической вставки в другое приложение. NeClip не запрашивает мониторинг ввода или запись экрана.

## Изменения в NeClip 3.0.0

Полностью удалены захват и редактор скриншотов, исправление раскладки, жест Option и запоминание языка по приложениям. Убраны их код, настройки, четыре сочетания клавиш и запросы разрешений. Остались пять разделов настроек и три глобальных сочетания.

Обновление сохраняет существующую базу, историю, изображения, файлы и сниппеты. Удаляются только 14 устаревших ключей настроек. Снимки, ранее сохранённые в истории как изображения, остаются доступными. Нативное редактирование сниппетов, Undo/Redo, поиск и резервные копии сохранены.

## Разработка и выпуск

Для сборки нужны полный Xcode и Swift 6.2 или новее. Единственная прямая зависимость — GRDB.swift 7.11.1 с фиксированной версией. Перед изменением кода запустите проверки:

```sh
scripts/secret-scan.sh
swift test --disable-sandbox
swift test --disable-sandbox -c release -Xswiftc -strict-concurrency=complete -Xswiftc -warnings-as-errors
ruby scripts/verify-site.rb
ruby scripts/test-site.rb
```

Для выпуска приложения дополнительно нужны проверки ASan и TSan, проверенный PR и все обязательные GitHub Actions. `build-app.sh` собирает указанный полный SHA коммита, подписывает приложение arm64, выполняет нотариализацию и stapling, проверяет Gatekeeper для DMG и приложения из финального ZIP, затем формирует контрольные суммы и provenance. Не помещайте секреты нотариализации в репозиторий.

NeClip распространяется напрямую через [GitHub Releases](https://github.com/AffPapa/neclip/releases). В Mac App Store приложение не публикуется. Публичные файлы нужно скачать и проверить независимо до обновления ссылок сайта.
