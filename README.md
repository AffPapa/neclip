# NeClip — менеджер буфера обмена для Mac и альтернатива Maccy, Paste и Raycast

NeClip — приложение для macOS, которое сохраняет историю буфера обмена, помогает работать со сниппетами и исправлять текст, набранный в неправильной раскладке EN/RU. В приложении также есть редактор скриншотов с непрозрачной маскировкой данных. NeClip работает в строке меню на Mac с Apple Silicon и macOS 14 или новее.

История и сниппеты остаются на этом Mac. Нет учётной записи, облачной синхронизации, рекламы, телеметрии и обработки содержимого буфера обмена с помощью ИИ. Автоматическая коррекция раскладки выключена по умолчанию.

**Ищете менеджер буфера обмена для Mac, локальную историю копирования или альтернативу Maccy, Paste либо Raycast?** Посмотрите [сравнение 20 приложений для Mac](https://affpapa.github.io/neclip/compare.html) и выберите вариант под свой сценарий.

## История копирования, сниппеты и сочетания клавиш

Скопируйте текст, откройте историю, выберите запись и нажмите Return. Если macOS разрешила NeClip использовать функцию универсального доступа, приложение отправит вставку в исходное приложение. Без этого разрешения оно скопирует выбранный элемент для ручной вставки. Command-Return копирует без вставки, Shift-Return вставляет обычный текст.

| Сочетание клавиш по умолчанию | Действие |
|---|---|
| Command-Shift-V | Открыть историю буфера обмена |
| Command-Shift-B | Открыть папки сниппетов |
| Command-Shift-2 | Снять область экрана |
| Command-Option-3 | Снять весь экран |
| Control-Command-V | Перейти к следующему недавнему элементу |
| Option-Shift-L | Вручную исправить раскладку EN/RU; повторить, чтобы отменить |
| Control-Option-A | Выключить автоматическую коррекцию раскладки |

Все семь глобальных сочетаний клавиш можно изменить. Если сочетание занято, приложение сохраняет предыдущую рабочую настройку и показывает альтернативный пункт меню. Щёлкните значок NeClip правой кнопкой, чтобы открыть сниппеты.

История поддерживает локальный поиск по тексту, типу, приложению и дате. Папки сниппетов можно создавать, переименовывать и удалять; сниппеты из удалённой папки остаются в библиотеке. Шаблоны поддерживают `{date}`, `{time}`, `{clipboard}`, `{date:iso}` и `{time:iso}`.

## Исправление неправильной раскладки EN/RU

Выделенный текст можно исправить вручную или включить дополнительный жест с отдельной клавишей Option. Экспериментальный автоматический режим анализирует вводимый токен по мере набора и изначально выключен. Распознавание использует локальные словари и начинается с четырёх символов; короткие и неоднозначные слова могут быть пропущены.

Для автоматического исправления нужны разрешения «Универсальный доступ» и «Мониторинг ввода». NeClip ограничивает обработку защищённых полей, терминалов, IDE, удалённых клиентов и ситуаций с неопределённым фокусом. Автокоррекция подходит не всем; её можно быстро выключить сочетанием Control-Option-A или пунктом меню.

## Скриншоты с маскировкой данных

После команды снимка экрана редактор позволяет закрыть область непрозрачной заливкой, добавить стрелки, фигуры и текст, отменить или повторить действие, а затем скопировать или сохранить результат в PNG/JPEG. Маскировка становится частью пикселей итогового изображения. Экспорт не содержит редактируемых слоёв и исходных метаданных изображения.

Снимок выбранного экрана создаётся только после команды пользователя. Для захвата экрана macOS запрашивает разрешение «Запись экрана»; отмена захвата не публикует изображение.

## Конфиденциальность и хранение данных

История хранится локально в `~/Library/Application Support/NeClip/neclip.sqlite`. Удаление приложения не удаляет эту базу. NeClip не выполняет автоматическое распознавание текста на изображениях. Чувствительные системные типы буфера и известные защищённые источники исключаются, но не все приложения сообщают о чувствительных данных надёжно.

Резервные копии — обычные пользовательские файлы, они не зашифрованы автоматически. Храните их в безопасном месте и сделайте резервную копию перед обновлением. Экспорт сниппетов в JSON объединяет папки с одинаковыми именами; для полной копии библиотеки используйте встроенную резервную копию базы.

Для обычной работы функция универсального доступа необязательна. Она нужна для автоматической вставки в другое приложение. Разрешения на мониторинг ввода и запись экрана запрашиваются только для соответствующих включённых функций.

## Изменения в NeClip 2.8.7

Поиск истории сохраняет стандартную работу клавиатуры в фильтрах, кнопках и при вводе через IME; модифицированные команды навигации передаются AppKit. Отключение истории изображений учитывается и для скриншотов, уже ожидающих записи. При совпадении заголовка поиск больше не преобразует всё тело записи к нижнему регистру.

Синтетический поиск по 64 записям с телами по 512 КиБ, 30 прогретых release-итераций: p50 164,965 → 3,741 мс; p95 229,571 → 4,187 мс. Это измерение поиска в SQLite и обработки строк, не полной задержки интерфейса.

## Разработка и выпуск

Для сборки нужны полный Xcode и Swift 6.2 или новее. Единственная прямая зависимость — GRDB.swift 7.11.1 с фиксированной версией. Перед изменением кода запустите проверки:

```sh
scripts/secret-scan.sh
swift test --disable-sandbox
swift test --disable-sandbox -c release -Xswiftc -strict-concurrency=complete -Xswiftc -warnings-as-errors
ruby scripts/verify-site.rb
ruby scripts/test-site.rb
```

Для выпуска приложения дополнительно нужны проверки ASan и TSan, проверенный PR и все обязательные GitHub Actions. `build-app.sh` собирает указанный полный SHA коммита, подписывает приложение arm64, выполняет нотариализацию и stapling, проверяет Gatekeeper для DMG и приложения из финального ZIP, затем формирует контрольные суммы и provenance. Не помещайте секреты нотариализации в репозиторий.

NeClip распространяется напрямую через [GitHub Releases](https://github.com/AffPapa/neclip/releases). В Mac App Store приложение не публикуется. Публичные файлы нужно скачать и проверить независимо до обновления ссылок сайта.
