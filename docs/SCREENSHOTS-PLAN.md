# Скриншоты NeClip — объединённое решение

Дата: 2026-09-10. Статус: реализация и проверки, не публичный релиз.

## Профессиональное задание

Роли: macOS-инженер, дизайнер взаимодействия, инженер обработки изображений и QA/privacy reviewer.
Объединить четыре исследования, отделить подтверждённые API от предположений. Реализовать небольшой нативный модуль для macOS 14+: одна переназначаемая клавиша → область экрана → пять инструментов → «Копировать» или «Сохранить…». Не добавлять аккаунты, облако, галерею, видео, OCR, историю исходных снимков или сторонний UI-runtime. Проверять геометрию, редактирование, безопасное скрытие и интеграцию с существующей приватностью. Не менять установленное приложение и публичный релиз в рамках этого среза.

### Что объединяем

- CleanShot X / Shottr: короткий путь от выделения к действию, видимые copy/save, отсутствие обязательного сохранения исходника.
- Flameshot / ksnip: простые инструменты разметки и undo; не переносим многостраничные настройки.
- Snapzy / capcap / ScreenCap: полезные открытые образцы нативной архитектуры; пишем собственную реализацию, не копируем непроверенные лицензированные фрагменты.
- Системные Screenshot / Preview: знакомые клавиатурные команды, native окна и панели, разрешение записи экрана только при первом использовании.
- Из дополнительных исследований принимаем тест независимости скрытых пикселей, проверку смены буфера при асинхронном экспорте и раздельную проверку масштаба X/Y.

### Расхождения и решения

| Предложение | Решение / причина |
|---|---|
| `SCScreenshotManager` | Да, macOS 14+. Одноразовый кадр, не постоянно работающий `SCStream`. |
| Новый `captureImage(in:)` только на macOS 26 | Исправление: доступен с macOS 15.2; для единого поведения 14+ используем display filter и собственное выделение. |
| Системный Markup нельзя встроить | Уточнение: публичный PaperKit появился на macOS 26. Не используем пока: поддержка 14+ потребовала бы двух редакторов. |
| PNG quality 0.85 / гарантированное сжатие в 10 раз | Нет: PNG lossless, lossy-quality не является регулятором PNG. Размер и скорость измеряем, не обещаем. |
| Blur / pixelate для скрытия секретов | Нет: только непрозрачная заливка; после разметки она накладывается последней и экспортируется в плоские пиксели. |
| Всегда уменьшать Retina вдвое | Нет: сохраняем пиксельную геометрию и читаемость текста. JPEG — явно выбранный формат. |
| Автоматически сохранять оригинал / temp на диск | Нет: исходник живёт в памяти одной сессии; в файл и clipboard попадает только финал. |
| В буфер TIFF, file URL и PNG одновременно | Только PNG: не раздуваем память и не публикуем временные пути. |
| Снимок сам попадёт в историю | Нет: у NeClip own-write guard. Нужна явная интеграция с лимитами, паузой и исключениями. |
| Новая библиотека hotkeys | Нет: расширяем существующий coordinator с проверкой конфликтов. |
| Запрос разрешения / прогрев захвата при запуске | Нет: только по команде пользователя. |
| Все мониторы / HDR / видео / scrolling | За пределами первого среза. Выделение на мониторе с указателем, SDR/sRGB. |

Подтверждение PaperKit: [Apple WWDC25 — Meet PaperKit](https://developer.apple.com/videos/play/wwdc2025/285/).
API: [SCScreenshotManager](https://developer.apple.com/documentation/screencapturekit/scscreenshotmanager), [ScreenCaptureKit](https://developer.apple.com/documentation/screencapturekit), [Image I/O](https://developer.apple.com/documentation/imageio).
Значения доступности также сверены с заголовками установленного Apple SDK. Рекомендации UX — [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/).

## UX-контракт

1. По умолчанию ⌘⇧2; пользователь может переназначить. Команда также доступна в меню.
2. Замороженный кадр на экране с указателем. Drag выделяет область, Escape отменяет. Исходник не копируется.
3. Компактное отдельное image-first окно: снимок занимает canvas, а внизу одна
   панель **Скрыть, Перо, Стрелка, Рамка, Текст** и действия Copy/Save.
4. Разметка не меняет оригинал. Undo/redo меняют команды, а не хранят множество bitmap-копий. Маски скрытия всегда выше остальных слоёв.
5. **Копировать** (⌘Return) — готовый PNG; **Сохранить…** (⌘S) — native save panel, PNG по умолчанию, JPEG по выбору. Нет неопределённого «Готово».
6. Настройки: горячая клавиша и папка сохранения. Цвет/толщина не превращаются в отдельные настройки первой версии.
7. Если во время подготовки PNG пользователь уже скопировал другое, не перезаписываем новое содержимое: предлагаем повторить явное копирование.
8. Save-only не меняет clipboard и историю. Copy следует лимитам/паузе/исключениям истории; запрет истории не запрещает явное копирование.

## План и gates

### P0 — ядро

- [x] Модель пяти инструментов и геометрия в пикселях.
- [x] Detached crop, SDR/sRGB bitmap, плоский PNG/JPEG без исходных метаданных.
- [x] Непрозрачная финальная маска, тест двух разных секретов под ней.
- [x] Tests: ориентация, отрицательные координаты дисплея, Retina, границы, отмена/undo.

### P1 — полезный вертикальный срез

- [x] Реализован одноразовый SCK capture с permission UX и единственной сессией; реальный захват — pending.
- [x] Затемнение показывается сразу; pending-shell инертен до кадра, свой overlay
  исключается по windowID, отмена защищена generation-токеном.
- [x] Реализованы выделение, редактор, клавиатура и защита закрытия; native structure/drag/Escape проверены программно.
- [x] Hotkey/menu/settings с конфликтами и сохранением.
- [x] Copy/save, generation check и интеграция истории без исходника; live PNG save и copy в изолированный clipboard подтверждены.
- [x] Изолированный редактор: пять инструментов, русская подпись, undo/redo и PNG сохранение проверены визуально на синтетике.
- [x] Live JPEG save: выбор формата, имени, папки, сохранение и декодирование результата.
- [x] Image-first editor: прозрачный titlebar, пропорциональный initial size,
  SF Symbols и компактный нижний toolbar без системного chrome.
- [ ] Реальный ScreenCaptureKit capture. Повторные AX timeouts не засчитываются как успешный UI test.

### Gate перед handoff

- [x] Baseline и новые тесты, release build, strict concurrency / warnings-as-errors.
- [x] Проверка diff, секретов и новых зависимостей (их нет).
- [x] Измерения размера до/после: stripped arm64 executable +107 792 байта (+2.50%); одинаковые release build flags, без test instrumentation.
- [x] Карта проекта: что проверено автоматически, что требует реального Screen Recording permission / multi-display hardware.

Уточнения из исполнения: ImageIO добавляет структурные EXIF (размер/цветовое пространство), а macOS может рекламировать TIFF-конверсию опубликованного PNG. Это не перенос оригинальных метаданных и не отдельная TIFF-копия, создаваемая NeClip. Маски скрытия проверены на идентичность итоговых PNG/JPEG при разных исходных секретах. Захват включает видимые окна NeClip: исключение всего собственного приложения могло бы раскрыть перекрытое содержимое вместо видимого пользователю окна.

Пользователь дополнительно разрешил установку новой сборки в `/Applications/NeClip.app`.
Она выполняется только после signing/notarization и с резервной копией для отката;
реальный capture проверяется сразу после установки. Публичный релиз остаётся
отдельным gate. Прототип с зелёной компиляцией не объявлять проверенной публичной версией.
