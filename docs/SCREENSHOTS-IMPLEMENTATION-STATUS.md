# Скриншоты — состояние реализации

Дата: 2026-09-10. Основа: текущая ветка `codex/neclip-screenshots` (UX/performance pass).
Локальный кандидат: **2.3.1/build 27**. Публичная версия остаётся **2.2.0/build 25**.

## Реализовано

- Переназначаемая ⌘⇧2 и команда «Скриншот области…» в меню.
- Одноразовый ScreenCaptureKit capture; выделение на экране с указателем, Escape, отмена при смене дисплеев.
- Пять инструментов: непрозрачное скрытие, перо, стрелка, рамка, текст.
- Нативное окно, undo/redo, масштаб по размеру / 100% / 200%, жестовое увеличение.
- Финальный PNG в буфер; системная панель сохранения PNG/JPEG; папка в существующих настройках.
- Плоский SDR/sRGB экспорт. Непрозрачные маски рисуются последними; исходные метаданные и слои не переносятся.
- Защита от изменения clipboard во время encode, own-write guard и явная запись только финального PNG в историю.
- История соблюдает паузу, ignore-next, исключения, image toggle, разрешение clipboard и лимиты. Save-only её не меняет.
- Исходник только в памяти одной сессии. Никакого фонового screen stream, OCR, облака или новой зависимости.
- Закрытие/выход защищены во время экспорта и при несохранённых пометках.
- При горячей клавише лёгкая оболочка затемнения показывается сразу, пока
  ScreenCaptureKit готовит кадр; до получения изображения drag заблокирован.
- Оболочка исключается из кадра по собственному `windowID`; pending capture
  защищён generation-токеном и отменяется Escape/сменой дисплея.
- Crop выделенной области выполняется в detached-задаче, не блокируя UI.
- Редактор переведён в image-first layout: прозрачный titlebar, canvas на всю
  рабочую область и единый компактный нижний strip с SF Symbols и русскими labels;
  начальный размер учитывает пропорции снимка.
- В selection overlay добавлена явная центральная инструкция «Проведите мышью,
  чтобы выделить область», отдельная подсказка Esc и короткий crosshair под
  курсором; подсказка скрывается после начала drag.

## Изоляция и диагностика

Свежая копия `NeClip Shot QA` успешно запускается через LaunchServices.
DEBUG QA использует отдельную базу, именованный тестовый clipboard и volatile паузу истории/раскладки даже при перезапуске Finder без переменных окружения.

Старые AX timeout не считаются доказательством зависания: sample показывает штатный idle run loop. Явное удержание weak AppDelegate добавлено как корректная защита времени жизни, но не выдано за доказанную причину всех таймаутов.

Первоначальный JPEG-сценарий прерывался `elementHasNoFrame` / AX timeout. В следующем проходе тот же системный сценарий успешно завершён: формат JPEG выбран, файл сохранён в тестовую папку. macOS выбрала допустимое расширение `.jpeg`. Выход декодирован и проверен визуально; это уже live evidence, а не только I/O unit test.

## Размер

Предыдущий чистый strict release с `strip -S -x`: baseline 4 310 048 байт, кандидат 4 417 840 байт (+107 792; +2.50%). Это размер executable, не DMG. После последних изменений размер нужно освежить. Бинарник после release-тестов с дополнительными символами нельзя использовать для сравнения.

## Установка и оставшиеся gates

Пользователь разрешил Screen Recording тестовой копии и затем явно попросил собрать и установить новую версию в «Программы». В системном списке подтверждён обычный NeClip; запись именно QA-копии не подтверждена. Пароль администратора пользователь вводит только сам в macOS.

Подписанная/notarized сборка установлена в `/Applications/NeClip.app` с исходным bundle ID, после проверки Gatekeeper и с резервной копией прежней 2.2.0. Программа запущена, бинарник совпадает с кандидатом. Инсталлятор восстанавливает старый app при ошибке замены/проверки. Данные не удалялись. Подробности: [RELEASE-2.3.0-STATUS.md](RELEASE-2.3.0-STATUS.md).

Пользователь подтвердил, что затемнение по ⌘⇧2 появляется. Полный SCK-кадр после
ускоренного shell пока не засчитан как отдельное live-доказательство; это не
основание объявлять публичный релиз.

Открыты: реальный SCK кадр и выделение, разные дисплеи/Spaces и реальные ошибки доступа к папке. Первая версия намеренно ограничена одним дисплеем, 32 MP, SDR/sRGB; HDR, cross-display selection, scrolling и видео не обещаны.

Установленная `/Applications/NeClip.app` не заменялась этим проходом: изменения
проверены в изолированной QA-копии и исходниках. Публичная 2.2.0/build 25 и
установленная ранее 2.3.0/build 26 остаются нетронутыми до отдельного release gate.
