Скачать NeClip 2.5.2 Посмотреть исходники

macOS 14+ · Apple Silicon · MIT · Developer ID · нотарифицировано Apple · аккаунт не нужен

Откройте DMG, перетащите NeClip в «Программы» и запустите оттуда. Значок появится в строке меню, не в Dock.

Локальная история без поиска, закреплений и облака; папки сниппетов сразу в меню. История всегда идёт от последнего копирования. Проверки выпуска.

Уже пользуетесь NeClip? Перед обновлением сохраните копию базы и экспорт сниппетов. Для отката сохраните предыдущую версию. Подробнее об обновлении.

Только то, что ускоряет работу

NeClip живёт в строке меню, не занимает Dock и вызывается одной комбинацией. Настройки, просмотр записей и редактор сниппетов открываются в отдельных окнах.

История

Недавние тексты, изображения и файлы. Выберите нужное в меню — NeClip сразу вставит запись.

Сниппеты

Готовые тексты по папкам. Выбор одной клавишей, понятный редактор и локальные подстановки даты, времени и текущего буфера.

Раскладка

Ручное исправление EN/RU, переназначаемые клавиши и осторожный авто-режим с отдельной кнопкой выключения.

Клавиатура прежде всего

Открыть историю⌘ ⇧ V
Открыть папки сниппетов⌘ ⇧ B
Исправить раскладку⌥ ⇧ L
Выключить автоисправление⌃ ⌥ A
Вставить без форматирования⇧ ↩
Только копировать⌘ ↩

Основные сочетания можно изменить в настройках. Папки сниппетов также открываются правым кликом по значку NeClip.

Приватность видна, а не спрятана

История хранится только на этом Mac. NeClip объясняет, зачем macOS запрашивает доступ к буферу, и не читает его, если доступ запрещён.

0 аккаунтов

Нет регистрации, подписки и облачной синхронизации.

0 телеметрии

Нет аналитики и фоновых сетевых запросов. Проверка обновлений запускается вручную.

Защита по умолчанию

Записи из защищённых менеджеров паролей, данные с системными пометками «скрытое» или «временное» и копирования с неизвестным источником не сохраняются.
