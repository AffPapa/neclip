Только то, что ускоряет работу

NeClip не открывает постоянное большое окно: живёт в menu bar, не занимает Dock и вызывается одной комбинацией.

История

Текст, изображения и файлы. Быстрый локальный поиск, закрепление, превью и лимиты без бесконечного роста базы.

Сниппеты

Готовые ответы по папкам, ключи поиска и локальные подстановки даты, времени и текущего буфера.

Раскладка

Ручное исправление EN/RU и осторожный авто-режим по пробелу — локально, с защитой полей и отменой.

Клавиатура прежде всего

Приватность видна, а не спрятана

История остаётся в SQLite на этом Mac. На новых macOS NeClip заранее объясняет системный доступ к буферу и не читает содержимое, если выбрано «Всегда запрещать».

0 аккаунтов

Нет регистрации, подписки и облачной синхронизации.

0 телеметрии

Нет аналитики и фоновых сетевых запросов. Проверка обновлений запускается вручную.

Защита по умолчанию

Парольные приложения, concealed/transient данные и неизвестный источник отклоняются.
