Скриншоты удалены из NeClip

Начиная с NeClip 3.0.0, захват экрана, разметка и экспорт скриншотов удалены. Ранее сохранённые изображения остаются в истории буфера; новые изображения по-прежнему можно копировать из других приложений.

NeClip теперь предназначен для истории буфера обмена и папок сниппетов. Существующая история и сниппеты сохраняются при обновлении.
