Исправление раскладки удалено из NeClip

Начиная с NeClip 3.0.0, ручное и автоматическое исправление EN/RU, жест Option и запоминание раскладки по приложениям удалены. Эти команды и настройки больше не доступны.

NeClip теперь предназначен для истории буфера обмена и папок сниппетов. Существующая история и сниппеты сохраняются при обновлении.
